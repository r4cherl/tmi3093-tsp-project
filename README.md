# tmi3093-tsp-project
A Python program to solve a 50-city symmetric Travelling Salesperson Problem (TSP) using:
1. Simulated Annealing (SA); and
2. Evolutionary Search, implemented as a Genetic Algorithm (GA).
   
The objective is to find a short tour that visits every city exactly once and returns to the starting city.
Must implement both algorithms, visualize their search behavior, conduct controlled experiments, and explain their
performance.

The project focuses on correct algorithm implementation, exploration and exploitation, algorithm design and parameter selection, reproducible experimentation, visualization and interpretation.
